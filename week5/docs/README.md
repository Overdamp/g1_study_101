# สัปดาห์ 5: เทรน: reward เปลี่ยนพฤติกรรมของ policy อย่างไร

> สถานะ: **ร่าง** (เขียน 10/11/2026) ปรับได้เมื่อเริ่มจริง
> แผนตัวจริง: vault `05 Study/Study Plan.md` · ภาพรวม: `~/g1_study/STUDY_PLAN.md`

## เป้าหมาย
1. อ่าน reward ของ G1-23DoF ออกทุก term: แต่ละตัวให้รางวัล/ลงโทษอะไร weight เท่าไหร่ ดึงกันยังไง
2. **ทดลองแบบนักวิทยาศาสตร์:** fine-tune จาก P3b โดยเปลี่ยน reward **1 ตัว** เทียบกับ run ควบคุม (ไม่เปลี่ยนอะไร) **ทายผลก่อน**
3. วัดผลเป็นตัวเลขด้วย `vel_eval.py` แล้วอธิบายได้ว่าผลต่างจากที่ทายเพราะอะไร

## คำถามทวน (ตอบโดยไม่เปิดโน้ต)
1. reward ต่อ step คำนวณยังไง ทำไมต้องคูณ `dt`
2. term ที่เป็นรางวัล กับ term ที่เป็นบทลงโทษ ต่างกันที่ฟังก์ชันหรือที่ weight
3. ทำไมการทดลองต้องมี run ควบคุมที่ fine-tune เท่ากันแต่ไม่เปลี่ยน reward
4. `track_linear_velocity` ใช้ `exp(−error²/std²)` ทำไมไม่ใช้ `−error²` ตรงๆ
5. ถ้าเปลี่ยน reward ต้องแก้ `deploy.yaml` ไหม แล้วถ้าเปลี่ยน kp ล่ะ
6. ทำไมคะแนน `vel_eval` ดีขึ้นแล้วยังไม่ควรเอาขึ้นหุ่นจริงทันที
