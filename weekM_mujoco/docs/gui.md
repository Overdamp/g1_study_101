## ปุ่มหลัก (จาก F1)
| ปุ่ม | ทำอะไร |
|---|---|
| `Space` | เล่น / หยุด |
| `←` / `→` | ถอย / เดินหน้า 1 step (ตอนหยุดอยู่) |
| `+` / `-` | เร่ง / ลดความเร็ว (ดูตัวเลขมุมบน) |
| `Tab` / `Shift+Tab` | ซ่อน/แสดงแผงซ้าย / แผงขวา |
| `[` / `]` | สลับกล้อง |
| `Esc` | กลับไปกล้องอิสระ |
| ดับเบิลคลิก (ซ้าย) | **เลือก body** (body ที่เลือกจะสว่าง) |
| `Page Up` | เลือก body แม่ของตัวที่เลือก (ไต่ขึ้นตาม tree) |
| ดับเบิลคลิกขวา | ย้ายจุดหมุนกล้องไปที่จุดนั้น |
| `Ctrl` + ดับเบิลคลิกขวา | กล้องตาม body นั้น (tracking) |
| scroll / ลากปุ่มกลาง | ซูม |
| ลากซ้าย | หมุนมุมมอง |
| ลากขวา (`Shift` = อีกแกน) | เลื่อนมุมมอง |
| **`Ctrl` + ลากซ้าย** | **บิด** body ที่เลือก (ใส่โมเมนต์) |
| **`Ctrl` + ลากขวา** | **ดึง** body ที่เลือก (ใส่แรง) ← ใช้แทน "ลากแขน" ในงาน 2.3, 3.7, 4.5 |
| `F1` / `F2` / `F3` / `F4` / `F5` | help / info / profiler / **sensor** / เต็มจอ |
| `Backspace` | reset (ใน unitree_mujoco = mj_resetData) |

ปุ่มของ **unitree_mujoco เท่านั้น** (main.cc:630–645): `9` เปิด/ปิดหนังยาง · `7` หรือ `↑` สั้นลง · `8` หรือ `↓` ยาวขึ้น
`m3`–`m6` ของเราทำปุ่ม 9/7/8 ให้เหมือนกัน และ `Space` = หยุด/เล่น (ทำเองใน `g1mj.run` เพราะ viewer แบบ passive ไม่ได้ step ให้)

## ตัวเลือกการแสดงผล (แผงซ้าย → Rendering / Visualization)
ตัวที่ใช้บ่อย มีปุ่มลัด (ตัวพิมพ์ใหญ่ไม่ต้องกด Shift) ถ้าปุ่มไหนไม่ตรง ให้ดูชื่อในแผงซ้ายแทน:
| ปุ่ม | แสดง | ใช้ทำอะไรกับหุ่นเรา |
|---|---|---|
| `C` | จุดสัมผัส (contact point) | เท้าแตะกี่จุด (M6 ได้ 4 จุดต่อเท้า) |
| `F` | ลูกศรแรงสัมผัส | ดูว่าเท้าไหนรับน้ำหนัก ตอน policy เดิน (M7) |
| `T` | โปร่งใส | มองเห็นข้อต่อด้านใน |
| `J` | แกนข้อต่อ | เห็นทิศหมุนของ hip pitch / roll / yaw |
| `I` | กล่อง inertia | เทียบขนาดมวลของแต่ละ link |
| `M` | จุดศูนย์กลางมวล | ทำไม PD ค้างท่าแล้วล้ม (M4): COM อยู่นอกฐานเท้า |
| `0`–`5` | เปิด/ปิด geom group | group 1 = mesh ที่เห็น (contype 0) · group 0 = mesh ชน |

## แผงขวา
- **Joint**: slider ของทุกข้อต่อ (หยุดก่อนแล้วค่อยลาก จะตั้ง qpos ตรงๆ)
- **Control**: slider ของ `ctrl` (แรงบิด เพราะ actuator ของเราเป็น `motor`)
  ⚠️ ใน unitree_mujoco slider Control จะ**ไม่มีผล** เพราะ bridge เขียน `ctrl` ทับทุก step ส่วนใน `python3 -m mujoco.viewer` ใช้ได้

## แผงซ้ายที่ควรรู้
- **Simulation**: Pause / Reset / Reload (โหลด XML ใหม่หลังแก้ไฟล์) / Load key / Save key / Copy state
- **Physics**: timestep, integrator, gravity, ปิด/เปิด contact, friction loss ฯลฯ แก้สดได้ (ลองปิด gravity ดู)
- **Watch**: พิมพ์ชื่อ field (เช่น `qpos`) + index (เช่น `23`) → เห็นค่าสด = มุมศอกซ้าย (rad)
- **File**: Save xml, Print model / Print data (เขียน MJMODEL.TXT / MJDATA.TXT)

## แบบฝึก M0 (ทำใน `python3 -m mujoco.viewer --mjcf=...scene_23dof.xml`)
1. กด Space ให้หุ่นล้มลงพื้น → Backspace (หรือปุ่ม Reset) → ลองใหม่ด้วย `←` `→` ทีละ step
2. ดับเบิลคลิกที่ปลายแขนซ้าย แล้วกด `Page Up` ไปเรื่อยๆ จนถึง pelvis นับว่าต้องกดกี่ครั้ง (= ความลึกของ tree)
3. เปิด `C` + `F` ระหว่างหุ่นนอนบนพื้น ส่วนไหนรับแรงมากสุด
4. ใช้ `Ctrl` + ลากขวา ดึงมือหุ่นขึ้น
5. เปิด F4 (Sensor) ดูกราฟ sensor ระหว่างดึง
6. Watch: ใส่ `qpos` index `23` แล้วลาก slider ของ left_elbow_joint ในแผง Joint ตัวเลขตรงกันไหม
7. Physics: ปิด gravity แล้ว Space ดู → เกิดอะไร ทำไม
8. **ทายก่อน**: ตั้ง timestep เป็น 0.02 (10 เท่า) แล้วเล่น จะเกิดอะไร

- ถ้า `Ctrl` + ลาก ไม่ทำงานในหน้าต่างของ `m3`–`m7` ให้ลองใน `python3 -m mujoco.viewer` ก่อน (แบบ passive บางเวอร์ชันลากไม่ได้)
